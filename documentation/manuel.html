🔄 Modes de Fonctionnement

Le Ksoloti Kontrol dispose de 4 modes sélectionnables au démarrage :

Mode Sélection (Démarrage)

  1. Bouton 1 enfoncé → Mode OTA (mise à jour)
  2. Bouton 2 maintenu :
    • Relâché après clignotement rose → Mode Standalone
    • Relâché après clignotement cyan → Mode WiFi Local
    • Maintenu après clignotement jaune → Mode WiFi AP
  3. Aucun bouton → Mode Standalone (par défaut)

🎧 Mode 1 : Standalone

  • WiFi : Désactivé
  • Interface web : Aucune
  • Performance : Maximale
  • Usage : Contrôle physique uniquement
  • LED : Clignotement rose (1s)

🌐 Mode 2 : WiFi Local

  • WiFi : Connexion au réseau local
  • Interface web : Accessible via ksolotikontrol.local
  • Configuration : WiFiManager si réseau indisponible
  • Performance : Excellente
  • LED : Clignotement cyan (2s)

📶 Mode 3 : WiFi Access Point

  • WiFi : Point d'accès "KsolotiKontrol-AP"
  • Interface web : 192.168.4.1
  • Mot de passe : ksoloti123
  • Note : Premier chargement peut nécessiter déconnexion/reconnexion
  • LED : Clignotement jaune (2s)

🔄 Mode 4 : OTA (Mise à jour)

  • Activation : Bouton 1 enfoncé au démarrage
  • Fonctionnalité : Mise à jour sans fil
  • LED : Progression colorée (voir section OTA)
💡 Recommandation : Utilisez le Mode WiFi Local pour une expérience optimale.

🔗 Connexion

Mode WiFi Local (Recommandé)

  1. Démarrez en Mode WiFi Local (bouton 2 bref)
  2. L'ESP32 se connecte automatiquement au dernier réseau
  3. Accédez à : http://ksolotikontrol.local
  4. Si le réseau a changé, utilisez le bouton "🔄 Changer WiFi"

Mode Access Point

  1. Démarrez en Mode WiFi AP (bouton 2 long)
  2. Recherchez le réseau WiFi "KsolotiKontrol-AP"
  3. Connectez-vous avec le mot de passe : ksoloti123
  4. Ouvrez : http://192.168.4.1
  5. Note : Si la page ne charge pas, déconnectez/reconnectez le WiFi

Changement de Réseau WiFi

  1. En mode WiFi Local, cliquez sur "🔄 Changer WiFi"
  2. Confirmez l'action
  3. Connectez-vous au réseau "KsolotiKontrol-Config"
  4. Sélectionnez votre nouveau réseau WiFi
  5. L'ESP32 redémarre avec la nouvelle configuration
💡 Astuce : L'interface web fonctionne sur tous les appareils (ordinateur, tablette, smartphone).

En-tête de l'Interface

  • 💾 Save to File : Exporter tous les presets vers un fichier JSON
  • 📁 Load from File : Importer des presets depuis un fichier JSON

Console de Debug

  • Boutons : Actualiser, Effacer

💾 Système de Presets

Principe

Le système utilise exclusivement les presets web (P1-P8). Les anciens presets du boîtier ne sont plus utilisés.

Sauvegarde d'un Preset

  1. Réglez vos paramètres audio, filtre, octave et assignations
  2. Cliquez sur le bouton S1 à S8 (Save)
  3. Le preset est sauvegardé avec toutes les valeurs actuelles

Chargement d'un Preset

Via l'interface web :

  1. Cliquez sur le bouton L1 à L8 (Load)
  2. Tous les paramètres sont restaurés automatiquement

Via le boîtier physique :

  1. Tournez l'encodeur rotatif pour naviguer (P1-P8)
  2. L'écran affiche : OOPP (OO=octave, PP=preset)
  3. Appuyez sur l'encodeur pour charger le preset
  4. L'écran affiche LOAd pendant 1 seconde
✅ Synchronisation : Le chargement physique met automatiquement à jour l'interface web !

🎛️ Assignations Physiques

Principe

Vous pouvez assigner n'importe quel paramètre audio aux 4 contrôles physiques :

Contrôle Couleur Description
IR1 (Capteur IR 1) Rose Capteur Sharp IR principal
IR2 (Capteur IR 2) Blanc Capteur Sharp IR secondaire
Fader2 Jaune Fader analogique 2
Fader3 Vert Fader analogique 3

Configuration des Assignations

  1. Dans la section "Assignations Physiques"
  2. Sélectionnez un paramètre pour chaque contrôle (ou "OFF")
  3. Les sliders assignés se colorent automatiquement
  4. Les assignations sont sauvegardées avec chaque preset

Nouveauté : Filtres Assignables

Les paramètres de filtre sont maintenant assignables :

  • Filter Cutoff (paramètre 22)
  • Filter Reso (paramètre 23)
  • Filter Type (paramètre 24)
💡 Astuce : Assignez Filter Cutoff à IR1 et Filter Reso à IR2 pour un contrôle expressif du filtre !

🎛️ Contrôles Physiques

Écran TM1637

Affichage 4 digits au format OOPP :

  • OO : Octave (-12 à +12, ex: "-2", " 0", "+5")
  • PP : Preset web sélectionné ("P1" à "P8")
  • LOAd : Affiché 1 seconde lors du chargement

Encodeur Rotatif

  • Rotation : Navigue entre les presets P1-P8
  • Appui : Charge le preset sélectionné

Boutons Push

  • Bouton 1 : Transpose vers le bas (octave)
  • Bouton 2 : Transpose vers le haut (octave)
  • Bouton 3 : Trigger HH

Capteurs Sharp IR

  • IR1 : Mapping logarithmique pour contrôle expressif
  • IR2 : Mapping linéaire standard
  • Stabilisation : Filtre anti-bruit intégré

Faders Analogiques

  • Fader1 : Désactivé (défaillant)
  • Fader2/3 : Contrôle linéaire inversé (haut=255, bas=0)
⚠️ Note : En mode web (système unifié), la transposition par boutons est désactivée. Utilisez les boutons OCT-/OCT+ de l'interface.

⚙️ Spécifications Techniques

Hardware

  • Microcontrôleur : ESP32-D0WD-V3
  • Fréquence : 240MHz, Dual Core
  • RAM : 320KB (16.3% utilisée)
  • Flash : 4MB (52.5% utilisée)
  • Résolution ADC : 12 bits (0-4095)

Communication

  • Protocole : ESP-NOW (50Hz)
  • DMX : 512 canaux, 4 blocs de 128
  • WiFi : Point d'accès 2.4GHz
  • Interface web : HTTP + WebSocket

Canaux DMX Utilisés

101-135 : Paramètres audio principaux (35 canaux) 1-4 : Contrôle RGB DMX (mode + RGB)

Système de Fichiers

  • LittleFS : Stockage des presets et assignations
  • Interface web : HTML/CSS/JS embarqués
  • Persistance : Sauvegarde automatique

Modes de Fonctionnement

  • Mode WiFi Local : Connexion réseau local + mDNS (ksolotikontrol.local)
  • Mode WiFi AP : Point d'accès intégré (192.168.4.1)
  • Mode OTA : Mise à jour sans fil avec progression LED
